# POS สหกรณ์ — Multi-tenant Web POS

ระบบขายหน้าร้านแบบเว็บ (Go + PostgreSQL + Next.js 14) สำหรับร้านค้าชุมชน/สหกรณ์ ใช้ร่วมกันได้หลายร้านใน 1 ระบบ
แทนที่โปรแกรม POS เดิมบน MS Access (pstorenusoft) พร้อมระบบย้ายข้อมูลเดิมและระบบปันผลรายปี

**ภาษา:** ไทย/อังกฤษ สลับได้ทุกหน้า · **ผู้ใช้:** พนักงานร้าน (POS/หลังร้าน), ผู้ดูแลระบบกลาง, สมาชิก (LINE LIFF)

## ความสามารถหลัก

| กลุ่ม | รายละเอียด |
|---|---|
| ขายหน้าร้าน (POS) | ยิงบาร์โค้ด, ส่วนลดรายการ/ท้ายบิล, ของแถม, ซีเรียล, รับชำระหลายช่องทางต่อบิล (เงินสด/โอน/บัตร/QR/ขายเชื่อ), เงินทอน, พักบิล/เรียกบิล, ยกเลิกบิล, คืนสินค้า, ใบเสร็จ 58/80 มม., เปิด-ปิดกะ + นับเงิน, บันทึกเปิดลิ้นชัก, โปรโมชัน |
| สินค้า/สต็อก | หมวดหมู่, หน่วยนับ, หลายบาร์โค้ดต่อสินค้า, ราคา 4 ระดับ, ต้นทุนล่าสุด/เฉลี่ย, สมุดสต็อก (ledger), รับสินค้าเข้า, ปรับสต็อก, ตรวจนับสต็อก, แจ้งเตือนสินค้าใกล้หมด, พิมพ์ป้ายบาร์โค้ด |
| สมาชิก/ลูกหนี้ | ทะเบียนสมาชิก, บัญชีหุ้น (ฝาก/ถอน), ยอดซื้อสะสม, ลูกหนี้ + รับชำระบางส่วน, อายุหนี้ |
| ปันผลรายปี | เกณฑ์ต่อปี (บาท/หุ้น, % ปันหุ้น, % เฉลี่ยคืน, ทุนสำรอง ฯลฯ), จำลอง → อนุมัติ → จ่าย, ใบแจ้งปันผลรายสมาชิก, ส่งออก CSV — สูตรตรงกับระบบเดิม 100 % |
| รายงาน | ยอดขายรายวัน/สินค้า/หมวด/พนักงาน/ชั่วโมง, กำไรขั้นต้น, สต็อก/มูลค่า/สินค้าไม่เคลื่อนไหว, ลูกหนี้, ซื้อจากผู้จำหน่าย, ค่าใช้จ่าย, งบกำไรขาดทุนอย่างง่าย, กราฟรายเดือน (ส่งออก CSV ได้ทุกรายงาน) |
| สมาชิกผ่าน LINE | บัตรสมาชิกดิจิทัล, ยอดซื้อ, ประมาณการปันผล, ผูกบัญชีด้วยรหัส/เบอร์โทร (โหมด mock จนกว่าจะมี LINE channel) |
| ระบบ | หลายร้าน (RLS แยกข้อมูล), บทบาทผู้ใช้ 5 ระดับ, audit log, ย้ายข้อมูลจาก Access แบบรันซ้ำได้ + รายงานกระทบยอด, AI ถาม-ตอบข้อมูล (NL→SQL, เปิดเมื่อ gateway พร้อม) |

## เริ่มต้นพัฒนา

ดู [CLAUDE.md](CLAUDE.md) (คำสั่งครบ) และ [docs/CONVENTIONS.md](docs/CONVENTIONS.md)

```bash
docker run -d --name pos-pg -e POSTGRES_USER=pos -e POSTGRES_PASSWORD=pos -e POSTGRES_DB=pos -p 54322:5432 postgres:16-alpine
cd backend && cp .env.example .env && go run ./cmd/seed -store BBR -store-name "ร้านทดสอบ" -owner owner -owner-password Owner12345 && go run ./cmd/api
cd frontend && npm install && npm run dev      # http://localhost:3010 → login: ร้าน BBR / owner / Owner12345
```

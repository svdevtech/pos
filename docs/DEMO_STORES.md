# ร้านตัวอย่างสำหรับสาธิตระบบ

ระบบนี้มีร้านตัวอย่างสองร้านไว้ใช้เวลานำเสนอหรือให้คนใหม่ลองเล่น โดยไม่แตะข้อมูลของสองร้านที่ใช้จริง
(`BBR` บ้านบุญเรืองเหนือ และ `KAEN` บ้านแก่นใต้)

| รหัสร้าน | ชื่อร้าน | ผู้ใช้ / รหัสผ่าน | ใช้สาธิตอะไร |
|---|---|---|---|
| `DEMOPOS` | ร้านค้าตัวอย่าง (สำหรับนำเสนอระบบ) | demo / Demo@2569pos | ขายหน้าร้าน สินค้า คลัง สมาชิก ลูกหนี้ รายงาน ปันผล |
| `DEMO` | ร้านตัวอย่าง (ทดลองระบบร้านอาหาร/กาแฟ) | demo / Demo@2569pos | เมนู ครัว ผังโต๊ะ QR โต๊ะ คิว จอง โปรโมชัน รายงานร้านอาหาร |

> รหัสผ่านชุดนี้เป็นรหัสสาธิตบนเว็บที่เปิดสาธารณะ เปลี่ยนได้ตลอดที่ **ตั้งค่า → ผู้ใช้**

---

## 1. `DEMOPOS` — ร้านค้าปลีก

ข้อมูลตัวอย่างคัดลอกมาจากสินค้าจริงของ `BBR` ผ่าน API (อ่านอย่างเดียว ไม่เขียนกลับไปที่ร้านต้นทาง)

- สินค้า 400 รายการ กระจายทุกหมวด มีบาร์โค้ด ราคาขาย ต้นทุน และสต็อกตั้งต้น
- หมวดสินค้าและหน่วยนับครบตามร้านต้นทาง · ผู้จำหน่าย 20 ราย
- สมาชิก 24 ราย พร้อมทุนเรือนหุ้นตั้งต้น
- บิลย้อนหลัง 7 วัน ประมาณ 90 ใบ (เงินสดเป็นส่วนใหญ่ ขายเชื่อ 1 ใน 6) เพื่อให้แดชบอร์ด กราฟ และรายงานมีข้อมูล
- เปิดกะไว้แล้วที่เครื่อง `POS1` เงินทอนตั้งต้น ฿2,000 จะได้เข้าหน้าขายได้ทันที

สร้างใหม่หรือเติมข้อมูลซ้ำได้ด้วย (รันจากโฟลเดอร์ `frontend`)

```bash
BASE=https://t-pos.tdev2022.com FROM=BBR FROM_USER=owner FROM_PASS=Owner12345 STORE=DEMOPOS POS_USER=demo POS_PASS=Demo@2569pos node scripts/pos-seed-demo.mjs
```

ปรับปริมาณได้ด้วยตัวแปร `PRODUCTS` (ค่าเริ่มต้น 400) `MEMBERS` (24) `DAYS` (7) `BILLS` (90)
สคริปต์รันซ้ำได้ สินค้าจับคู่ด้วยรหัสสินค้า สมาชิกจับคู่ด้วยรหัสสมาชิก และจะไม่เพิ่มบิลถ้าร้านมีบิลในช่วงนั้นอยู่แล้ว

ถ้าต้องการร้านเปล่าใหม่ก่อนเติมข้อมูล

```bash
ssh ubuntu-server 'cd /data/pos/src/deploy && docker compose --env-file /data/pos/.env run --rm --entrypoint /app/seed api -store DEMOPOS -store-name "ร้านค้าตัวอย่าง (สำหรับนำเสนอระบบ)" -owner demo -owner-password "Demo@2569pos"'
```

## 2. `DEMO` — ร้านอาหาร/กาแฟ

เมนูตัวอย่างของโมดูลร้านอาหาร 3 สถานีครัว 6 หมวด 18 เมนูพร้อมสูตรตัดวัตถุดิบทุกรายการ
7 กลุ่มตัวเลือก 3 โซน 14 โต๊ะ

```bash
BASE=https://t-pos.tdev2022.com STORE=DEMO POS_USER=demo POS_PASS=Demo@2569pos node scripts/fnb-seed-demo.mjs
```

เมนู **ร้านอาหาร / กาแฟ** จะโผล่ในแถบซ้ายเฉพาะร้านที่มีเมนูอาหารจริง ดังนั้น `DEMO` เห็น ส่วน `DEMOPOS`
กับสองร้านที่ใช้จริงจะไม่เห็น

## 3. ลำดับการนำเสนอที่แนะนำ

1. `DEMOPOS` → แดชบอร์ด ดูยอดวันนี้ กราฟรายชั่วโมง สินค้าขายดี
2. `DEMOPOS` → ขายหน้าร้าน กด F1 ค้นหาสินค้า ขายจริงหนึ่งบิล รับเงินสด พิมพ์ใบเสร็จ
3. `DEMOPOS` → สินค้า คลังสินค้า เช็คสต็อก สมาชิก ลูกหนี้ รายงาน ปันผล
4. `DEMO` → ร้านอาหาร/กาแฟ สั่งหน้าเคาน์เตอร์ จอครัว ผังโต๊ะ QR โต๊ะ จอเรียกคิว รายงานเมนู

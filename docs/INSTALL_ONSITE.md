# ติดตั้งหน้าร้านให้ลูกค้า: เครื่องพิมพ์ ลิ้นชักเงิน เครื่องยิงบาร์โค้ด และการตั้งค่า

เอกสารนี้สำหรับ **คนที่ไปติดตั้งระบบที่ร้าน** (ไม่ใช่ผู้ใช้งานทั่วไป — ผู้ใช้อ่าน `USER_GUIDE.md`)
ครอบคลุมอุปกรณ์ที่ต้องเตรียม วิธีตั้งค่าเครื่อง วิธีตั้งค่าในระบบ และ **สิ่งที่ระบบยังไม่รองรับ** ซึ่งต้องบอกลูกค้าก่อนส่งมอบ

ตรวจสอบล่าสุด `2026-09-04` เวอร์ชัน `232da03` บน https://t-pos.tdev2022.com

## 1. สรุปสถานะฟังก์ชันที่เกี่ยวกับฮาร์ดแวร์

| ฟังก์ชัน | สถานะ | รายละเอียด |
|---|---|---|
| **พิมพ์ใบเสร็จ** | ✅ ใช้งานได้จริง | สร้าง HTML ใบเสร็จ → พิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ ใช้ได้กับเครื่องพิมพ์ทุกตัวที่ติดตั้งในเครื่อง (ความร้อน 58/80 มม. หรือ A4) |
| **ความกว้างกระดาษ 58/80 มม.** | ✅ ใช้งานได้จริง | ตั้งที่ ตั้งค่า → ใบเสร็จ มีผลกับ `@page size` และความกว้างเนื้อหาจริง (58 → 48 มม./ฟอนต์ 10.5px, 80 → 72 มม./ฟอนต์ 12px) |
| **พิมพ์ซ้ำ / สำเนา** | ✅ ใช้งานได้จริง | ใบเสร็จสำเนามีคำว่า "สำเนา" และบิลที่ยกเลิกมีคำว่า "ยกเลิกแล้ว" |
| **พิมพ์ป้ายบาร์โค้ด** | ✅ ใช้งานได้จริง | สินค้า → พิมพ์ป้ายบาร์โค้ด จัดหน้า A4/A5 แล้วสั่งพิมพ์ |
| **พิมพ์คู่มือในเว็บ** | ✅ ใช้งานได้จริง | หน้าคู่มือมีปุ่มพิมพ์ ซ่อนเมนูให้อัตโนมัติ |
| **พิมพ์รายงาน** | ⚠️ **ยังใช้ไม่ได้จริง** | หน้ารายงานมีแต่ **ส่งออก CSV** ไม่มีปุ่มพิมพ์ ถ้ากด Ctrl+P ตารางรายงานจะพิมพ์ออกมา **ไม่มีข้อมูล** (เห็นแต่หัวตาราง) เพราะตารางใช้ virtual scrolling |
| **พิมพ์ใบสรุปกะ (X/Z report)** | ⚠️ **ยังไม่มี** | ปิดกะแล้วดูสรุปบนจอได้ แต่พิมพ์สลิปสรุปกะไม่ได้ |
| **เปิดลิ้นชักเงิน (ปุ่ม F10)** | ⚠️ **ไม่ได้สั่งเปิดลิ้นชักจริง** | ปุ่มนี้บันทึก log ว่าใครเปิดลิ้นชักเมื่อไร (ตรวจสอบย้อนหลังได้) แต่ **ไม่ได้ส่งสัญญาณไปที่ลิ้นชัก** — ดูวิธีทำให้ลิ้นชักเปิดจริงในข้อ 4 |
| **โลโก้บนใบเสร็จ** | ⚠️ **สวิตช์มีแต่ยังไม่ทำงาน** | อัปโหลดโลโก้ได้ และมีสวิตช์ "แสดงโลโก้บนใบเสร็จ" แต่ใบเสร็จที่พิมพ์ออกมายังไม่มีโลโก้ |
| **ปัดเศษเงินสด** | ⚠️ **ตั้งค่าได้แต่ยังไม่ทำงาน** | ค่าถูกบันทึก แต่ระบบยังไม่ปัดเศษยอดสุทธิให้ |
| **ภาษาใบเสร็จ** | ⚠️ **ตั้งค่าได้แต่ยังไม่ทำงาน** | ใบเสร็จใช้ **ภาษาที่หน้าจอกำลังแสดงอยู่** ไม่ได้ใช้ค่าที่ตั้งไว้ |
| **พอร์ตลิ้นชัก / พอร์ตจอลูกค้า (COM)** | ⚠️ **เก็บค่าไว้เฉยๆ** | ย้ายมาจากระบบเดิมเพื่อไม่ให้ข้อมูลหาย ระบบเว็บยังไม่ต่อกับพอร์ต COM |

> เรื่องที่ติด ⚠️ ทั้งหมดแก้ได้ แต่ยังไม่ได้ทำ — ควรตกลงกับลูกค้าก่อนว่าจำเป็นไหม ก่อนวันติดตั้ง

## 2. อุปกรณ์ที่ต้องเตรียม

| อุปกรณ์ | ข้อกำหนด | หมายเหตุ |
|---|---|---|
| เครื่องหน้าร้าน | Windows 10/11 หรือ Android หรือ iPad | Windows คุมอุปกรณ์ได้ครบที่สุด |
| เบราว์เซอร์ | Chrome / Edge เวอร์ชันล่าสุด (iPad ใช้ Safari) | Chrome/Edge เท่านั้นที่พิมพ์เงียบได้ (ข้อ 3.3) |
| เครื่องพิมพ์ใบเสร็จ | ความร้อน 58 หรือ 80 มม. + ไดรเวอร์ Windows | ยี่ห้อที่ใช้กันมาก: Xprinter, EPSON TM-T82/T88, Gprinter |
| ลิ้นชักเงิน | ต่อสาย RJ11 เข้าช่อง **DK/Cash Drawer** ของเครื่องพิมพ์ | อย่าซื้อรุ่นที่ต้องต่อ COM/USB ตรงเข้าคอมพิวเตอร์ |
| เครื่องยิงบาร์โค้ด | แบบ USB/Bluetooth **HID (keyboard wedge)** | ตั้งให้ส่ง Enter ต่อท้าย |
| เน็ตเวิร์ก | ต่ออินเทอร์เน็ต/LAN ถึงเซิร์ฟเวอร์ได้ | ถ้าจะใช้กล้องสแกน **ต้องเป็น https** (ข้อ 5) |

## 3. ตั้งค่าเครื่องพิมพ์ใบเสร็จ

### 3.1 Windows (แนะนำสำหรับเครื่องหลักหน้าร้าน)

1. ติดตั้งไดรเวอร์ของเครื่องพิมพ์ (ตามแผ่น/เว็บผู้ผลิต) แล้วสั่ง **Print Test Page** ให้ผ่านก่อน
2. **Settings → Printers & scanners** → ตั้งเครื่องพิมพ์ใบเสร็จเป็น **ค่าเริ่มต้น (Default)**
3. เข้า **Printing Preferences** ของเครื่องพิมพ์ → ตั้ง **Paper size** ให้ตรงกับม้วนกระดาษ
   - ม้วน 80 มม. → เลือก `80 x 297 mm` หรือ `80mm x Receipt`
   - ม้วน 58 มม. → เลือก `58 x 297 mm`
   - ถ้าไม่มีให้เลือก ให้สร้าง **Custom paper size** กว้าง 80 (หรือ 58) มม. ยาว 297 มม.
4. ปิด **ตัวเลือกกระดาษต่อเนื่อง/Cut** ตามที่ร้านต้องการ (ปกติเปิด auto-cut ไว้)

### 3.2 ตั้งค่าหน้าต่างพิมพ์ของ Chrome (ทำครั้งเดียว Chrome จะจำไว้)

กดพิมพ์ใบเสร็จครั้งแรก แล้วตั้งในหน้าต่างพิมพ์:

| ช่อง | ตั้งเป็น |
|---|---|
| Destination / ปลายทาง | เครื่องพิมพ์ใบเสร็จ |
| Paper size | 80mm (หรือ 58mm) ตามม้วนกระดาษ |
| Margins / ระยะขอบ | **None** |
| Scale / มาตราส่วน | **100** (อย่าใช้ Fit to page) |
| Headers and footers | **ไม่ติ๊ก** (ไม่งั้นจะมี URL/วันที่ติดมาบนกระดาษ) |
| Background graphics | ไม่ติ๊ก |

### 3.3 พิมพ์อัตโนมัติโดยไม่มีหน้าต่างพิมพ์ (แนะนำมากสำหรับหน้าร้าน)

ถ้าไม่ทำข้อนี้ แคชเชียร์ต้องกด "Print" ทุกบิล วิธีทำให้พิมพ์ทันที:

1. สร้าง shortcut ของ Chrome บนเดสก์ท็อป → คลิกขวา → **Properties**
2. ในช่อง **Target** เติมท้ายบรรทัด (เว้นวรรคก่อน):

```bash
--kiosk-printing --app=https://ที่อยู่เว็บของร้าน/pos
```

3. เปิดร้านด้วย shortcut นี้เท่านั้น — `window.print()` จะพิมพ์เข้าเครื่องพิมพ์ค่าเริ่มต้นทันทีโดยไม่ถามอะไร
4. ในระบบ เปิด **ตั้งค่า → ใบเสร็จ → พิมพ์ใบเสร็จอัตโนมัติ** ไว้ด้วย

> ทดสอบเสมอว่า Default printer คือเครื่องพิมพ์ใบเสร็จ เพราะ kiosk-printing จะไม่ถามและพิมพ์เข้าเครื่องเริ่มต้นเสมอ

### 3.4 iPad / Android

- **iPad**: พิมพ์ผ่าน **AirPrint** เท่านั้น → ต้องใช้เครื่องพิมพ์ที่รองรับ AirPrint หรือมี print server ในเครือข่าย
  เครื่องพิมพ์ความร้อน USB ธรรมดา **ต่อกับ iPad ตรงๆ ไม่ได้**
- **Android**: ติดตั้ง print service ของผู้ผลิต หรือใช้เครื่องพิมพ์ที่รองรับ Google Cloud/Default Print Service
- ถ้าร้านใช้ iPad เป็นเครื่องขายและอยากได้ใบเสร็จ ทางที่ถูกที่สุดคือมี **เครื่องพิมพ์แบบ LAN/Wi-Fi ที่รองรับ AirPrint** หนึ่งตัว

## 4. ลิ้นชักเงิน

ระบบเว็บ **สั่งเปิดลิ้นชักเองไม่ได้** (เบราว์เซอร์ไม่มีสิทธิ์คุยกับพอร์ต COM/USB) วิธีที่ใช้กันจริงในร้านคือ **ให้เครื่องพิมพ์เป็นคนเปิด**

1. ต่อสาย RJ11 จากลิ้นชัก → ช่อง **DK / Cash Drawer** ที่ท้ายเครื่องพิมพ์ใบเสร็จ (ไม่ใช่ช่องโทรศัพท์)
2. เปิด **Printing Preferences** ของเครื่องพิมพ์ → หา **Cash Drawer / Peripheral / เปิดลิ้นชัก**
3. ตั้งเป็น **Open before printing** หรือ **Open after printing** (แล้วแต่ไดรเวอร์) สำหรับ **Drawer 1**
4. ทดสอบ: ขายบิลเงินสด 1 บิล → ใบเสร็จออก + ลิ้นชักเด้ง

**ผลที่ได้จริง**
- ลิ้นชักจะเปิด **ทุกครั้งที่พิมพ์ใบเสร็จ** — พอสำหรับการขายปกติ
- ปุ่ม **เปิดลิ้นชัก (F10)** ในระบบ **จะไม่เปิดลิ้นชัก** มันแค่บันทึกประวัติว่าใครเปิดตอนไหน (ดูได้ที่ ตั้งค่า → บันทึกการใช้งาน)
- ถ้าลูกค้าต้องการให้ปุ่ม F10 เปิดลิ้นชักได้จริง มี 2 ทาง — **ต้องพัฒนาเพิ่ม**
  1. ให้ปุ่มพิมพ์สลิปเปล่า 1 บรรทัด (ลิ้นชักจะเปิดตามการตั้งค่าไดรเวอร์) — ทำได้เร็ว ใช้ทางพิมพ์เดิม
  2. ทำโปรแกรมเล็กๆ ติดตั้งที่เครื่องเพื่อส่ง ESC/POS ตรงเข้าเครื่องพิมพ์ — ยืดหยุ่นกว่า แต่ต้องติดตั้งเพิ่มทุกเครื่อง

## 5. เครื่องยิงบาร์โค้ดและกล้อง

- **เครื่องยิงบาร์โค้ด USB/Bluetooth**: เสียบแล้วใช้ได้เลย ไม่ต้องตั้งค่าในระบบ
  ตั้งที่ตัวเครื่องยิงให้ **ส่ง Enter (CR) ต่อท้าย** ตามคู่มือของเครื่อง (สแกนบาร์โค้ดตั้งค่าในเล่ม)
  ระบบดักการยิงได้แม้เคอร์เซอร์ไม่ได้อยู่ในช่องสแกน
- **กล้องแท็บเล็ต/มือถือ**: กดไอคอนกล้องท้ายช่องสแกน
  **ต้องเปิดเว็บผ่าน https เท่านั้น** (หรือ `localhost`) ถ้าเปิดด้วย `http://192.168.x.x:3010` เบราว์เซอร์จะไม่ให้ใช้กล้อง — ระบบจะขึ้นข้อความ "ต้องเปิดผ่าน https"
- เครื่อง PDA ที่มีหัวยิงในตัว ใช้ได้เหมือนเครื่องยิง USB

## 6. ตั้งค่าในระบบ (ไล่ตามลำดับตอนติดตั้ง)

### 6.1 เปิดร้านและผู้ใช้
1. ผู้ดูแลแพลตฟอร์มสร้างร้าน (`DEPLOY.md` ข้อ 5) → ได้รหัสร้าน + บัญชีเจ้าของร้าน
2. **ตั้งค่า → ผู้ใช้งาน**: เพิ่มพนักงานทีละคน กำหนดบทบาท
   - เจ้าของร้าน = ทำได้ทุกอย่าง · ผู้จัดการ = ยกเลิกบิล/ตรวจสลิป/รายงาน · แคชเชียร์ = ขายอย่างเดียว
   - **เปลี่ยนรหัสผ่านเริ่มต้นทุกบัญชีก่อนส่งมอบ**

### 6.2 ข้อมูลร้าน (ตั้งค่า → ข้อมูลร้าน)
- ชื่อร้าน (ตามที่ต้องการให้ขึ้นหัวใบเสร็จ), ที่อยู่, เบอร์โทร, เลขประจำตัวผู้เสียภาษี
- **ข้อความหัวใบเสร็จ / ท้ายใบเสร็จ** (เช่น "ขอบคุณที่ใช้บริการ")
- โลโก้: อัปโหลดได้ แต่ยังไม่ขึ้นบนใบเสร็จ (ดูข้อ 1)

### 6.3 ใบเสร็จและพฤติกรรมหน้าขาย (ตั้งค่า → ใบเสร็จ)

| ตั้งค่า | แนะนำสำหรับร้านทั่วไป |
|---|---|
| ความกว้างกระดาษ | ให้ตรงกับม้วนกระดาษจริง (58 หรือ 80) |
| พิมพ์ใบเสร็จอัตโนมัติ | เปิด (คู่กับ kiosk-printing ข้อ 3.3) |
| ต้องเปิดกะก่อนขาย | เปิด ถ้าร้านนับเงินเข้า-ออกกะ |
| อนุญาตแก้ราคาที่หน้าขาย | ปิด (เปิดเฉพาะร้านที่ต่อราคาได้) |
| อนุญาตขายเมื่อสต็อกไม่พอ | เปิดช่วงแรกที่สต็อกยังไม่ตรง แล้วค่อยปิดเมื่อตรวจนับเสร็จ |
| แป้นตัวเลขในหน้าต่างชำระเงิน | อัตโนมัติ (แสดงเองบนจอสัมผัส) |
| **พร้อมเพย์** | ใส่เบอร์พร้อมเพย์ของร้าน + ชื่อผู้รับเงินภาษาอังกฤษ **แล้วต้องทดสอบสแกนด้วยแอปธนาคารจริง 1 ครั้ง** |
| การปัดเศษเงินสด | ยังไม่ทำงาน — ไม่ต้องตั้ง |
| ภาษาใบเสร็จ | ยังไม่ทำงาน — ใบเสร็จตามภาษาหน้าจอ |
| พอร์ตลิ้นชัก/จอลูกค้า | เว้นว่างได้ (ยังไม่ใช้งาน) |

### 6.4 ข้อมูลตั้งต้น
1. **หน่วยนับสินค้า** → **หมวดหมู่** → **สินค้า** (หรือนำเข้าจากระบบเดิม: ตั้งค่า → ข้อมูลและการสำรอง)
2. **สมาชิก** และทุนเรือนหุ้น (ถ้าเป็นสหกรณ์)
3. **ตรวจนับสต็อกครั้งแรก** ให้ตรงก่อนเปิดขายจริง
4. ตั้ง **สำรองข้อมูลอัตโนมัติ** และทดสอบดาวน์โหลดไฟล์สำรอง 1 ครั้ง

- [ ] ขายเงินสด → **ลิ้นชักเปิด** (ถ้าตั้งค่าไดรเวอร์ตามข้อ 4)
- [ ] กดพิมพ์ซ้ำบิลเดิม → มีคำว่า "สำเนา"
- [ ] ขายด้วย QR พร้อมเพย์ → **สแกนด้วยแอปธนาคารจริง** ต้องขึ้นชื่อบัญชีร้านและยอดตรง
- [ ] ถ่ายรูปสลิปแนบบิล แล้วเปิดดูจากเมนูสลิปได้
- [ ] เปิดกะ–ปิดกะ นับเงิน ส่วนต่างถูกต้อง
- [ ] ส่งออกรายงานยอดขายเป็น CSV แล้วเปิดด้วย Excel ได้
- [ ] สำรองข้อมูล 1 ครั้ง แล้วดาวน์โหลดไฟล์สำเร็จ
- [ ] เปลี่ยนรหัสผ่านทุกบัญชีเรียบร้อย
- [ ] แจ้งลูกค้าเรื่องที่ยังไม่รองรับ (ตารางข้อ 1) และตกลงว่าจะทำเพิ่มหรือไม่

## 8. ถ้าลูกค้าต้องการเพิ่ม (ยังไม่ได้ทำ)

| สิ่งที่ขอ | ต้องทำอะไร |
|---|---|
| พิมพ์รายงานลงกระดาษ A4 | ทำหน้า "มุมมองสำหรับพิมพ์" ของแต่ละรายงาน (ตารางธรรมดา ไม่ virtual scroll) + ปุ่มพิมพ์ |
| พิมพ์ใบสรุปกะ (X/Z report) | ทำสลิปสรุปกะบนกระดาษความร้อน ใช้ทางพิมพ์เดียวกับใบเสร็จ |
| ปุ่ม F10 เปิดลิ้นชักจริง | พิมพ์สลิปเปล่า 1 บรรทัด หรือทำโปรแกรมส่ง ESC/POS ที่เครื่อง |
| โลโก้บนใบเสร็จ | ใส่รูปโลโก้ (base64) ลงหัวใบเสร็จ + เคารพสวิตช์ "แสดงโลโก้" |
| ปัดเศษเงินสด | คำนวณปัดเศษตอนคิดเงินสด ทั้งฝั่งเซิร์ฟเวอร์และใบเสร็จ |
| ภาษาใบเสร็จแยกจากภาษาหน้าจอ | ให้ใบเสร็จอ่านค่า `receipt_locale` แทน locale ของหน้าจอ |
| จอแสดงราคาลูกค้า (customer display) | ต้องมีโปรแกรมที่เครื่อง เพราะเบราว์เซอร์ต่อพอร์ต COM ไม่ได้ |
